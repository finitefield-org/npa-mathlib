# Registry Reconciliation for npa-mathlib 0.2.4

This audit authorizes promotion-origin registry reconciliation from the
released npa-mathlib 0.2.1 package snapshot to the validated mutable
npa-mathlib 0.2.4 catalog.

The 0.2.1 registry predates recurring direct-catalog synchronization. Since
that snapshot, the catalog has accumulated verified module additions and
in-place artifact revisions while its v1 registry continued to preserve the
0.2.1 identities. The reconciliation transaction may migrate that history to
registry v3, append exact current identities, and introduce target-only owners
for current modules that have no source-backed promotion row.

No rename, replacement, split, merge, or retirement is authorized by this
audit. The command must therefore infer only same-name unchanged modules,
same-name revisions, and new modules. It must reject any removed module or
lifecycle relation unless a separate canonical change request is supplied.

The 0.2.1 and 0.2.4 package gates, generated projections, certificate
identities, theorem inventories, and axiom policy remain authoritative. This
audit and the generated reconciliation attestation are governance evidence
with `proof_evidence: false`; neither replaces source-free certificate
verification.
