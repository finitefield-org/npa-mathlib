# Legacy Promotion-Origin Registry Bootstrap

Status: accepted

Date: 2026-07-15

This audit reserves every public `Mathlib.*` module present in npa-mathlib
version 0.2.1 before the package-generic promotion-origin registry was
introduced. The exact target source, certificate-file, certificate, export,
axiom-report, and theorem-statement identities are recorded as unresolved
legacy target rows in `promotion-origins.json`.

Historical source routes are deliberately not inferred. Each target remains
active and reserved until a later governed migration can prove and record a
canonical source origin. This audit and the registry are governance metadata,
not proof evidence; canonical certificates and source-free reference
verification remain authoritative.
